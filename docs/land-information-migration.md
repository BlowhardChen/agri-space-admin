# 土地信息迁移

入口为「土地管理 → 土地信息」，路由仍为 `/land/msg`。菜单、鉴权、面包屑和标签页沿用现有动态路由，无须另加路由模块。

## 已迁移

- 正常/退地列表、统计、关键字、四级行政区划、高级筛选、合并/单个地块切换。
- 地图边界、流转/托管样式、列表与地图选择联动、合并子块展开和聚焦、侧栏折叠、缩放、定位、底图切换。
- 基础信息与合同详情，基础资料编辑、合同新增/修改、付款日期与合同金额计算。
- 单个/批量转移、合并预览、逆地理编码、截图上传、合并保存、更名、子地块移出、退地、恢复、删除确认、Excel 导出。

合并沿用 Vue 源页面的凸包算法，实际亩数为所选地块业务面积之和；托管地块不能合并。源代码中子地块操作误用父 ID、单条转移参数形状不一致和合并未等待请求完成的问题已修正。移出操作仅提交所选子地块的 `landId`，需在真实后端联调时确认其语义。

## 接入地约后端

仓库已默认接入地约正式服用于认证和菜单：开发环境通过 Vite 代理访问 `http://admin.xtnf.com/web`，测试和生产环境直接请求该地址。正式服使用 `POST /login`、`GET /getRouters`，令牌以 `Authorization: Bearer <token>` 发送；登录页不再展示仅供本地演示的验证码登录与自助注册。

如需在其他环境覆盖接口地址，可在对应的 `.env.*.local` 设置：

```dotenv
VITE_API_URL=/api
VITE_API_PROXY_TARGET=http://admin.xtnf.com/web
VITE_USE_MOCK_AUTH=false
```

修改环境变量后需重启开发服务，并使用有效业务账号登录。生产部署若使用 HTTPS 页面而正式服仍为 HTTP，需要由部署网关同源转发或将后端升级为 HTTPS，避免浏览器拦截混合内容。

土地管理默认由 `VITE_USE_MOCK_LAND=true` 提供本地地约风格模拟数据，不会请求正式服的土地、行政村、逆地理编码、上传或导出接口。模拟数据覆盖正常/退地列表、统计、详情、筛选、编辑、合同、转移、合并、子地块移出和 CSV 导出，操作结果仅保留在当前页面运行期间。若后续需要真实土地数据，可在对应 `.env.*.local` 设置 `VITE_USE_MOCK_LAND=false`。

地图使用 EPSG:4326 经度/纬度数据，进入 OpenLayers 时转换为 EPSG:3857。标准底图使用 OpenStreetMap，卫星底图通过 `VITE_MAP_SATELLITE_URL` 配置（默认沿用迁移源中的卫星服务地址）；未复制源项目硬编码的天地图密钥。瓦片服务需允许跨域读取，否则合并截图会提示失败并保留表单，切换标准地图后可重试。

依赖使用 npm 安装的 OpenLayers 8.2 与 Turf 6.5，继续维护 `package-lock.json`。`yarn.lock` 保持迁移前内容。现有 Vite 与旧版 Node 类型声明存在 peer 约束冲突，重新安装时需要延续 `npm install --legacy-peer-deps`。

## 验证记录

本地开发页面使用浏览器拦截的测试接口验证，未向真实后端提交写入：

- 路由和列表、选择及地图生命周期、筛选应用/重置。
- 合同金额和付款计算、合同 ID/地块 ID、基础编辑保留土地 ID 和 GPS。
- 子地块移出目标、单条转移 ID/类型、合并地址/截图上传/保存。
- 退地恢复、异常重试、取消删除不提交、Excel 下载。

全仓 ESLint 及新增页面的 Prettier、Stylelint 已检查。未运行构建命令。此前全仓 `tsc --noEmit` 的登录页 `visibilityToggle` 类型兼容问题已在正式服认证改造中修复，需在本次修改后重新执行类型检查确认。

真实业务账号、线上数据、真实后端写入、卫星瓦片可用性及浏览器定位权限仍需部署环境联调。
